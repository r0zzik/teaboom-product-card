# Карточка товара Teaboom

Тестовое задание на позицию HTML-верстальщика / Frontend-верстальщика.

## Что реализовано

- Карточка товара: изображение, категория, название, фасовки, артикул, цены, кнопка «В корзину», описание
- Переключение фасовок (цена, старая цена, артикул)
- Кнопка «В корзину» с состоянием (обычное / в корзине) по каждой фасовке
- Кнопка «В избранное» с переключением состояния
- Кнопка «Оставить отзыв»
- Увеличение изображения (модальное окно)
- Хлебные крошки
- Адаптив: 1440px, 768px, 375px

## Стек

- HTML5
- CSS (Flexbox, Grid)
- JavaScript (без фреймворков)

## Как запустить

Открыть index.html в браузере или запустить через Live Server.
